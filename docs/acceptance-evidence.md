# Acceptance Evidence Matrix

Maps master specification §11 acceptance criteria AC-01…AC-18 to the tests, commands and artifacts that prove them. A mocked integration is never recorded as tested live; unconfigured providers are `blocked`.

Status vocabulary: `not-started` · `in-progress` · `blocked` · `passed`

**As of Phase 12 (2026-09-08):** `passed` — AC-01, AC-02, AC-04, AC-05, AC-07, AC-10, AC-16. `in-progress` (logic proven locally, live-provider or owner-sign-off evidence outstanding) — AC-03, AC-06, AC-08, AC-09, AC-11, AC-12, AC-14, AC-15, AC-17, AC-18. `blocked` — AC-13 (Shadowfax account). See `docs/release-candidate.md` for the RC evidence review and the ordered blocker list.
